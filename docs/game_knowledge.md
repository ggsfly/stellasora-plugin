# 星塔旅人游戏知识库

本文件记录 LLM 在回答用户问题时需要了解的游戏机制知识。
这些知识无法从字典或攻略页直接获取，需要预先注入。

## 纹章（Emblem）系统

### 纹章形状与等级

每个角色可装备 3 个纹章——70级（三角形）、80级（圆形）、90级（六边形）；每个纹章有 4 个词条，词条稀有度 绿<蓝<金<彩。

| 等级 | 形状 |
|------|------|
| 70级 | 三角形 |
| 80级 | 圆形 |
| 90级 | 六边形 |

### 纹章推荐表格结构（重要）

攻略中的纹章（Emblem）推荐是一个**不定行数、3 列的表格**：

| | 70级纹章（三角形） | 80级纹章（圆形） | 90级纹章（六边形） |
|---|---|---|---|
| 行1 | 词条A | 词条B | 词条C |
| 行2 | 词条D | 词条E | 词条F |
| ... | ... | ... | ... |

- **第 1 列** = 70 级纹章（三角形）需要的词条
- **第 2 列** = 80 级纹章（圆形）需要的词条
- **第 3 列** = 90 级纹章（六边形）需要的词条
- **行代表一组推荐属性**
- **行与行之间无优先顺序**，回答时必须**一次性完整给出所有行**，不能省略、不能只挑前几行
- **输出格式规范**：回答纹章推荐时按 `70级：词条A，B，C` / `80级：词条D，E，F` / `90级：词条G，H，I` 分行给出，每级词条顺序 = 网页表格中该列自上往下的顺序。

### 词条选择规则

回答纹章推荐问题时，必须按以下结构组织：

1. **先按纹章槽位分类**：每个角色有多个纹章槽位，不同槽位推荐的词条不同
2. **再按等级分类**：70级（三角形）、80级（圆形）、90级（六边形）各自需要选择什么词条
3. **词条顺序即网页自上而下顺序，无优先级排序**（条目之间无优先顺序）

## 秘纹（Disc / Runic Disc）系统

- "秘纹" = "Disc" = "Runic Disc"，是同一种装备的不同称呼
- 秘纹分为主位秘纹（Main Disc）和支援位秘纹（Support Disc）
- 主位秘纹提供基础属性与技能加成，技能加成分 旋律（Melody）/和声（Harmony）两类
- 支援位秘纹提供基础属性与音符加成

## 预设码（Preset Code）

- 预设码是一串编码文本（如 `AAAAkAAAAKAAAACCMAYjZAAwBsBsBs2AIGwA`）
- 玩家在游戏内通过"跳转 → 预设 → 导入预设"使用
- 一个预设码对应一套完整的潜能（Potential）配置
- 不同队伍流派有不同的预设码

## 角色养成

### 等级突破素材

角色升至满级（Lv.90）需要的素材在 stelladb 角色页的 "Next upgrade cost" 区块中。
技能满级素材在 "Next skill upgrade cost" 区块中。

### 技能升级优先度

技能升级优先度在 stelladb /infodoc/<元素> 页面的 "Skill Upgrade Priority" 区块中。
格式如 `1/1/10/1 (Support Skill only)`，表示四个技能等级推荐。
