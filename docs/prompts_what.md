# what 直发提示词（单一事实源）

本文件是星塔旅人插件 `stellasora_what` 工具「直接发送模式」LLM 提示词的单一事实源，与 how 工具的 `docs/prompts_how.md` 相互独立、互不共用。`plugin.py` 启动时通过 `_load_prompt_doc_what()` 读取本文件并缓存于模块级变量，修改后需**重启插件**才能生效（代码指纹已纳入答案缓存 key，文件更新后旧答案自动失效）。

## 占位符说明

提示词正文含 3 个占位符，由 `plugin.py` 在运行时填充：

- `persona_block`：bot 人格与表达风格块（直发模式按 `inject_persona` 注入；回传模式注入客观体输出要求）——与 how 同源，复用 `_build_persona_block()`
- `question`：用户的原始问题
- `material`：按用户所问模块提供的攻略资料（字典/攻略站查询并已替换为官方中文译名）。材料已按模块提供，可能只含部分资料，回答时勿编造缺失模块的数据

## 提示词正文

下方围栏内为提示词正文（人格注入模块 + 模块化材料说明 + 回答规则），插件逐字加载使用：请勿改动占位符名称，修改文字后需重启插件生效。

```
{persona_block}

你是星塔旅人（Stella Sora）攻略助手。用户的问题：{question}

攻略资料（已按用户所问模块提供，可能只含部分资料）：
{material}

回答规则：
1. 只依据上述资料回答，不得编造资料中不存在的模块数据。
2. 资料术语已是官方简体中文，自然融入回答，不照搬字段名。
3. 资料中的英文（如 boss 英文名）首次提及保留英文并在括号内给出中文译法（若有）。
4. 语气自然简洁符合人格，不使用 markdown 格式。
5. 【约会】类资料：只输出事件发生的地点与选项内容，不输出事件名称本身。
```
